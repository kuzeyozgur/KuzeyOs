# Face AI Showcase

This directory is a simplified public demonstration of the KuzeyOS Face AI concept.

It is **not the production Face AI source code**.

The included `app.py` uses synthetic responses only and does not perform real camera capture, face detection or face recognition.

The production implementation is maintained privately.

## Production Concepts Demonstrated

The real Face AI architecture uses technologies and concepts including:

- Local camera processing
- YuNet face detection
- SFace face recognition
- Face tracking
- Recognition events
- Edge-to-Core communication

No biometric data, production models, identities, face photographs or recognition galleries are included in this public repository.
