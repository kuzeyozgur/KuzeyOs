# KuzeyOS Node Showcase

This directory is a simplified public demonstration of the KuzeyOS Node concept.

It is **not the production source code**.

The included `app.py` is a synthetic example used only to illustrate the type of API exposed by the architecture.

Production functionality such as system administration, device control, credentials, private integrations and privileged operations is intentionally excluded.

## Demonstrated Concepts

- Central KuzeyOS node
- Status API
- Event representation
- Device representation
- Edge-oriented architecture

For the complete system design, see the documentation in `/docs`.
